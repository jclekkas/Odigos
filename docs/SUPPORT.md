# Support the project

The hosted analyzer at [odigosauto.com](https://odigosauto.com) is free. That is the main way to use Odigos. Self-hosting is optional and does not require a paid plan.

The most useful help is a sourced correction to [`data/state_fees.json`](../data/state_fees.json). Many states are still marked `needs_source`. A statute, DMV, revenue department, or attorney-general link that states the number is enough to open an issue.

Bug reports with the personal details removed from the quote are the next most useful thing. See [CONTRIBUTING.md](../CONTRIBUTING.md).

There is no subscription and no donation requirement.
